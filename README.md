# Skill Setu — AI Bridge

Skill Setu is a frontend prototype demonstrating an Academia-to-Industry career bridge experience for students, colleges, and recruiters.

## Prototype scope

- Student bridge-readiness dashboard
- Skill-gap radar and micro-assessment
- Smart skill-match feed
- Application tracker
- Bilingual career-coach demo
- Verified profile demo
- College dashboard
- Recruiter dashboard
- Dark mode and low-bandwidth UI controls

> This repository contains a frontend prototype/demo. The displayed datasets and AI responses are local demo data; no production backend, authentication, database, or live job integration is included.

## Run locally

```bash
npm install
npm start
```

## Production build

```bash
npm run build
```

The production output is generated in `build/`.
